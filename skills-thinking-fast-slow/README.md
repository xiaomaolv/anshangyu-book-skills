# 《思考，快与慢》— 卡尼曼认知偏见技能包

从丹尼尔·卡尼曼经典著作《思考，快与慢》(Thinking, Fast and Slow) 蒸馏出的 9 个 Claude Code 可执行技能。

## 安装

```bash
cp -r */ ~/.claude/skills/
```

## 技能列表

| # | 技能 | 章节 | 一句话 |
|---|------|------|--------|
| 1 | `two-systems` | 1-5 | 系统1快/直觉，系统2慢/理性 |
| 2 | `anchoring-effect` | 11 | 任何数字都会锚定你的判断 |
| 3 | `availability-heuristic` | 12 | 容易想起≠经常发生 |
| 4 | `regression-to-mean` | 17 | 极端之后自然回归≠干预有效 |
| 5 | `overconfidence` | 18-22 | 用区间预测校准你的自信 |
| 6 | `planning-fallacy` | 23 | 你的估算÷3才是真实时间 |
| 7 | `loss-aversion` | 26-28 | 损失的痛苦≈收益快乐的2倍 |
| 8 | `framing-effect` | 34 | 换个说法，换种选择 |
| 9 | `remembering-vs-experiencing` | 35-38 | 记忆=峰值+终点，过程不重要 |

## 推荐场景

- 做决策前 → `two-systems` 检查是直觉还是分析
- 谈判/定价 → `anchoring-effect`
- 做计划/排期 → `planning-fallacy`
- 风险判断 → `availability-heuristic`
- 放弃/止损 → `loss-aversion`
- 方案呈现 → `framing-effect`
