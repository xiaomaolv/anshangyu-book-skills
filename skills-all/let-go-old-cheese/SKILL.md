# 放弃旧的奶酪

## I — 方法论骨架

哼哼的问题不是找不到新奶酪,而是他**不愿意离开已经没有奶酪的地方**。他每天回到奶酪C站,凿墙壁,等待,抱怨——把所有精力花在一个已经空了的站。

"越早放弃旧的奶酪,你就越早发现新的奶酪。"这不是鸡汤,是生存法则。

唧唧转变的关键时刻:他问自己"你希望到哪里去找奶酪——这里还是迷宫中？"这个问题让他意识到:继续留在原地=100%饿死,走入迷宫=可能饿死也可能找到。**继续旧行为的期望值是负的,改变至少有机会。**

## E — 可执行步骤

1. 明确写出你还在"等"什么——那件你希望"恢复原样"的事
2. 问自己:"这个东西还会回来吗？" 如果答案是否定的或不确
3. 算一笔:如果现在放弃,最坏情况是什么？如果继续等,最坏情况是什么？
4. 写唧唧的那句话贴在可见处:"如果你不改变,你就会被淘汰"

## B — 边界

- 不适用于短期挫折(项目失败1次≠奶酪永远没了)
- "放弃"≠不学习教训,失败的经验是你在迷宫中积累的方向感
