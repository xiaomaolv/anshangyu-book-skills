# 以心为本

## I — 方法论骨架

稻盛和夫的经营哲学根基:**以心为本**。不是以制度为本,不是以绩效为本。

1. **做正确的事**: 决策的标准不是"能不能赚钱",是"作为人,这样做对不对"
2. **保护员工**: 危机中决不裁员——不是经济决策,是心性的选择
3. **身先士卒**: 领导者自己先做到,再要求别人
4. **透明经营**: 财务对所有员工公开,让大家知道公司真实的状况

稻盛说:京瓷能在泡沫经济中独善其身,不是因为战略多么英明,而是因为"以心为本"让员工在关键时刻选择了信任公司而非逃离。

## E — 可执行步骤

1. 遇到一个两难决策时,不问"哪个利润高",问"哪个让我晚上睡得着"
2. 对团队公开一个"之前一直保密"的信息,观察反应
3. 这个月做一件"只为员工考虑,不为公司赚钱"的事
