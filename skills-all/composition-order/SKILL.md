# 构图：从混乱中找出秩序

## I — 方法论骨架

克莱门茨定义构图: **"从混乱中找出秩序。"** 现实世界是混乱的,摄影师的工作是从中框选出一个有秩序的画面。

秩序通过以下要素建立:
- **趣味中心**: 画面中"让人神注其间"的关键点
- **引导线**: 线条将视线引向趣味中心
- **明暗分布**: 亮的区域自然吸引视线
- **形状对比**: 大vs小、规则vs不规则

**中国画论类比**: "锁笔"——"烟柳溪潭,偶著桥梁,松杉蓊郁,中安精舍,使人神注其间。" 这"神注其间"之处就是趣味中心。

## E — 可执行步骤

1. 看场景,先确定你要让观众看什么(趣味中心)
2. 用取景框裁掉一切不服务趣味中心的元素
3. 检查:视线进入画面后,有没有元素把它引向趣味中心？没有的话加一个(前景/引导线/明暗过渡)
4. 最后问:如果去掉趣味中心,这张照片还剩什么？如果一无所有→构图成功
