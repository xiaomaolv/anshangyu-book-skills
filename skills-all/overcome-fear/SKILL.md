# 穿越恐惧

## I — 方法论骨架

唧唧在奶酪C站的墙上写下了最关键的一句话: **"如果你无所畏惧,你会怎样做呢？"**

恐惧有两面:
- 有益的恐惧:让你在悬崖边退后一步
- 有害的恐惧:让你在奶酪已经没了的地方继续等待

唧唧的方法是**在脑海中先预演成功**:他闭上眼睛,想象自己"在迷宫中探险,找到了各种美味的奶酪,正在尽情享用"。这个画面给了他走进黑暗迷宫的勇气。

关键转变:恐惧的对象从"在迷宫中迷路"变成"在原地饿死"。当后者比前者更可怕时,行动就变得不难了。

## E — 可执行步骤

1. 写下你害怕的具体是什么(不能写"失败",要具体到"被拒绝"/"赔10万"/"丢面子")
2. 问:"如果我不害怕,我现在会做什么？" 写出答案
3. 闭眼30秒,想象你已经成功做完了这件事,看到画面
4. 迈出最小的一步——唧唧是"深吸一口气,朝右侧缓步跑去"

## B — 边界

- 不是让你无视真正的风险
- 勇敢≠鲁莽,唧唧也是先评估了"饿死在原地"比"在迷宫中迷路"更糟才动身的
