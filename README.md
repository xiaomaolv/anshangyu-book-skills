## 一、股票交易 Skill

### 1. 持仓标的
当前主要持仓股票为：
- **金发科技**
- **洛阳钼业**
- **银华创新药ETF**

其他标的如多氟多、钒钛股份、哈药股份等，仅作为观察标的，不做主要持仓分析。

---

### 2. 总仓位红线
1. 大盘结构性行情下，股票总仓位最高不超过 **50% 总资产**，常备 **50% 现金**。
2. 震荡弱势、主线不清晰时，总仓位控制在 **30%以内**。
3. 单只个股/ETF最高仓位不超过 **12% 总资产**，避免单一品种重仓。
4. 持仓以分批止盈、动态止损为主，禁止追高开、禁止亏损补仓摊低成本。

---

### 3. 标的分析规则
#### 金发科技
- **核心属性**：改性塑料、特种工程塑料、LCP、AI服务器材料、汽车材料
- **分析重点**：
  - 关注半年报业绩与 Q1 利润延续性
  - 关注 LCP、高温尼龙等新材料放量情况
  - 关注原油价格与石化原料成本变化
- **操作风格**：稳健修复型，适合低吸波段，不适合追涨停博弈
- **风险点**：若中报业绩低于预期，谨防估值兑现回落

#### 洛阳钼业
- **核心属性**：铜、钴、钼、钨等有色金属资源龙头
- **分析重点**：
  - 关注铜价、钴价、钼价走势
  - 关注全球宏观经济、美联储政策、大宗商品周期
  - 关注公司资源储量、产能释放与成本控制
- **操作风格**：周期资源标的，行情高度依赖宏观定价和商品价格
- **风险点**：金属价格波动大，板块弹性较强，不适合频繁短线追涨

#### 银华创新药ETF
- **核心属性**：覆盖创新药企、CXO、生物医药研发全产业链的行业指数基金
- **分析重点**：
  - 跟踪集采、医保谈判、医药行业顶层政策变动
  - 跟踪CXO订单景气度、药企临床管线落地、行业整体盈利周期
  - 跟踪北向资金、避险资金在医药板块的流向变化
- **操作风格**：成长行业指数，适配中长期分批布局+波段止盈，不宜短线爆炒
- **风险点**：政策收紧、行业研发进度不及预期会压制板块估值，指数回撤波动偏大

---

### 4. 交易执行标准
#### 建仓规则
- **不高开追仓**：标的单日大涨后，不建议次日高开直接加仓。
- **优先回踩低吸**：更安全的介入方式是价格回踩关键支撑位后分时企稳再考虑。
- **分批建仓**：总资金分 2—3 批介入，不一次性满仓。
- **只在浮盈时加仓**：持仓盈利后才可考虑顺势加仓，亏损状态禁止补仓。

#### 止盈规则
- 单只标的短线盈利达到 **8%—12%**，可先减仓一部分。
- 标的进入明显压力区或放量滞涨时，分批止盈。
- 周期个股、行业ETF逢利好兑现时，不要盲目格局鱼尾行情。

#### 止损规则
- 短线持仓跌破关键支撑位，应立刻执行止损控制风险。
- 亏损单不允许越跌越补。
- 总账户净值出现大幅回撤时，优先降仓防守而非被动扛单。

---

### 5. 禁止行为
1. 涨停、大阳线后重仓追入个股/ETF。
2. 被套后不断加仓摊低成本。
3. 单只个股、单只ETF仓位超过 **12%**。
4. 未划定支撑位、止损位就随意建仓。
5. 把短线题材炒作行情当成长期重仓配置逻辑。
6. 脱离行业基本面，仅凭K线涨跌盲目交易。

---

### 6. 复盘输出格式
每次股票复盘必须固定输出：
1. **当前持仓**：金发科技、洛阳钼业、银华创新药ETF
2. **每只标的状态**：强势 / 震荡 / 走弱
3. **关键价位**：支撑位、压力位、止损位
4. **操作计划**：持有、减仓、低吸、观望
5. **仓位检查**：是否符合总仓位和单标的12%仓位限制
6. **纪律检查**：是否存在追涨、亏损补仓、重仓等违规行为
