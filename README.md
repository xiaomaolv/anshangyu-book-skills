# 优化后 YAML 结构化 Skill 文档
优化要点：
1. 规范 YAML 头部元数据格式，增加标签、适用范围、权限约束字段
2. 层级统一缩进，拆分模块、子项、约束、输出范式，阅读层级清晰
3. 重复规则做提炼归集，删除冗余表述，规则边界更锋利
4. 禁止项、红线、执行标准分区隔离，醒目不易混淆
5. 复盘模板标准化固化，字段释义补齐
6. 全文用词统一、句式规整，机器解析+人工查阅双友好
7. 区分【刚性红线（绝对不可违反）】【执行标准（操作规范）】【分析依据（研判方向）】三类属性

```yaml
---
# 基础元数据
name: personal-life-master-skill
alias: 个人全域管控中枢
description: 统一接管【股票交易、学习计划、日常健身运动、乒乓球专项训练】四大业务模块，所有行为必须严格遵从内置刚性规则，AI仅依据规则输出方案、研判结果，禁止自主主观推演、自由发挥、随性优化规则
version: 1.1
update_date: 2026-07-30
trigger_words:
  - 股票类：股票分析、个股操作、建仓布局、持仓风控、盘面复盘、价位研判、止盈止损执行
  - 生活类：制定学习方案、健身规划、乒乓球训练指导、训练复盘、运动计划调整
scope: 个人投资交易管理 + 自我提升作息运动管理
hard_mode: true # 刚性模式，所有红线规则零容错
---

# ====================== 模块一：股票交易管控体系（最高优先级刚性约束） ======================
stock_system:
  # 1. 持仓池划分（严格区分主力持仓 / 观察备选）
  position_pool:
    main_hold_list: # 日常分析、交易操作核心标的
      - 金发科技
      - 洛阳钼业
      - 银华创新药ETF
    watch_only_list: # 仅行情观测，不主动规划建仓、不做持仓分析
      - 多氟多
      - 钒钛股份
      - 哈药股份

  # 2. 全域仓位刚性红线（不可突破，优先校验）
  position_red_line:
    total_asset_rule:
      structural_bull: 总仓位上限50%，永久预留50%现金底仓
      weak_shock_market: 主线模糊/弱势震荡行情，总仓位强制≤30%
    single_variety_limit: 单只个股/单只ETF占用总资产比例最高12%
    trading_principle: 全程采用分批止盈+动态止损机制；严禁高开追入、严禁亏损加仓摊薄成本

  # 3. 主力标的专属研判框架
  target_analysis_frame:
    金发科技:
      core_business: 改性塑料、特种工程塑料、LCP材料、AI服务器配套材料、车用塑料原料
      focus_dimension:
        1. 半年报业绩数据 & 一季度利润走势延续性
        2. LCP、高温尼龙等新材料产能出货放量进度
        3. 国际原油走势、上游石化原材料成本波动
      trading_property: 稳健修复波段标的，只适合回踩低吸，排除涨停短线博弈玩法
      hidden_risk: 中期财报业绩不及预期，易出现利好兑现后的估值回调
    洛阳钼业:
      core_business: 铜、钴、钼、钨等稀缺有色金属核心资源企业
      focus_dimension:
        1. 铜、钴、钼大宗商品现货&期货价格走势
        2. 全球宏观经济、美联储货币政策周期、大宗整体周期位置
        3. 企业矿产储量、产能释放节奏、开采生产成本管控
      trading_property: 强周期品种，涨跌高度绑定大宗商品定价，板块波动弹性大
      hidden_risk: 金属价格快速下行，板块追涨极易被套
    银华创新药ETF:
      core_business: 覆盖创新药企、CXO、医药研发全产业链宽基指数基金
      focus_dimension:
        1. 集采政策、医保谈判、医药行业顶层监管政策变化
        2. CXO行业订单景气度、药企临床管线落地进度、板块整体盈利周期
        3. 北向资金、避险资金在生物医药板块的资金流向
      trading_property: 成长赛道指数，适配中长期分批布局+波段止盈，禁止短线频繁炒作
      hidden_risk: 行业政策收紧、药企研发成果不及预期，指数回撤幅度偏大

  # 4. 标准化交易执行细则
  execution_spec:
    build_position: # 建仓要求
      rule1: 标的单日大阳线/大涨后，次日高开阶段禁止加仓、开仓
      rule2: 标准介入方式：价格回踩关键支撑位 + 分时走势企稳后择机低吸
      rule3: 单笔计划资金拆分为2~3批分次进场，禁止一次性满仓介入
      rule4: 仅现有持仓产生浮盈状态下才可顺势加仓；持仓亏损时禁止任何补仓行为
    take_profit: # 止盈要求
      rule1: 单标的短线浮动盈利8%~12%区间，执行部分减仓兑现收益
      rule2: 价格触及强压力位、K线放量滞涨，分批逐层止盈离场
      rule3: 周期股、行业ETF迎来利好落地兑现时，不贪恋鱼尾行情
    stop_loss: # 止损要求
      rule1: 短线持仓有效跌破预设关键支撑位，无条件立刻止损离场
      rule2: 所有亏损持仓，禁止越下跌越加仓摊平成本
      rule3: 账户整体净值出现大幅回撤，第一操作是降仓防守，不被动死扛持仓

  # 5. 永久禁止行为清单（违规即判定交易失误）
  forbidden_behavior:
    - 个股/ETF涨停、大阳线冲高后重仓追涨入场
    - 持仓被套后持续加仓摊薄持仓成本
    - 单个标的持仓占总资产比例突破12%上限
    - 未提前划定支撑位、止损位，盲目随意开仓建仓
    - 将短期题材炒作行情，当做长期重仓配置逻辑
    - 脱离公司基本面、行业周期，单纯依靠K线涨跌情绪化交易

  # 6. 固定复盘输出模板（复盘必须严格按该字段依次输出，不得缺项）
  review_output_template:
    1. 当前全部持仓清单：金发科技、洛阳钼业、银华创新药ETF
    2. 各标的行情状态判定：强势 / 震荡整理 / 走势走弱
    3. 价位数据：支撑价位、压力价位、预设止损价位
    4. 当期实操方案：继续持有 / 分批减仓 / 回踩低吸布局 / 保持观望
    5. 仓位合规校验：核对总仓位、单标的仓位是否匹配仓位红线要求
    6. 交易纪律自检：排查本次操作是否存在追涨、亏损补仓、超限重仓等违规行为

# ====================== 模块二：学习 / 日常运动 / 乒乓球训练管控体系 ======================
life_management_system:
  execution_rule: 该模块原有全部规则保持原状不作修改，AI需严格依照既定制度落地执行、输出对应方案与复盘内容
```

## 优化带来的几点优势
1. **结构分层清晰**：元数据→股票大模块（池子/仓位/标的/执行/禁令/复盘）→生活模块，逻辑自上而下递进
2. **刚性内容高亮隔离**：红线、禁止行为单独区块，执行时一眼识别禁区
3. **复盘模板格式化**：固定字段不会遗漏复盘要素，输出格式统一规整
4. **YAML语法标准**：缩进、列表、键值对规范，可直接被解析类工具读取使用
5. **语义拆分干净**：把原来混杂的文字拆成结构化键值，修改、增补规则时只需要改动对应节点
