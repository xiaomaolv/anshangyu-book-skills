# 个人全能Skill 完整大全介绍（personal-life-master-skill）
## 一、Skill基础信息
1. 技能名称：personal-life-master-skill
2. 版本：1.1
3. 核心定位：一站式个人生活管控技能，整合股票交易、自主学习、居家健身、乒乓球专项训练四大模块，所有输出严格遵循内置固定规则，禁止AI自由发挥、主观随意给出建议，全部方案标准化、有明确约束红线。
4. 触发关键词：股票分析、个股操作、建仓布局、持仓风控、盘面复盘、制定学习方案、健身规划、乒乓球训练指导、训练复盘
5. 使用载体：腾讯SkillHub + WorkBuddy，免费个人自用，无需开通SkillPay付费功能；两种调用方式：全局挂载永久生效 / 对话内手动指令启用。

## 二、四大模块完整功能详解
### 模块1：股票交易管控模块（核心持仓：金发科技、洛阳钼业、创新新材）
#### 1. 持仓划分规则
- 主力持仓：金发科技、洛阳钼业、创新新材，分析、复盘、操作计划优先围绕三者展开；
- 多氟多、钒钛股份、哈药股份仅作为观察标的，不作为重仓操作参考。
#### 2. 硬性仓位风控红线（不可突破）
1. 市场结构性行情，股票+基金总仓位上限50%，必须留存50%现金；
2. 行情震荡、无明确主线，总仓位控制30%以内；
3. 单只个股/基金持仓占总资产最高12%，杜绝单票重仓；
4. 铁律：仅浮盈持仓可顺势加仓，亏损被套严禁补仓摊薄成本；杜绝大涨次日高开追入。
#### 3. 三只标的专属分析逻辑
1. **金发科技**
改性塑料、LCP服务器材料、汽车塑料；重点跟踪原油成本、半年报业绩、高端新材料产能；走势偏震荡修复，只适合低吸波段，不追涨停；业绩不及预期存在回调风险。
2. **洛阳钼业**
铜钴钼钨周期资源龙头；行情绑定铜、钴大宗商品价格+全球宏观流动性；波动大，不适合频繁短线操作，以分批止盈、移动止损为主。
3. **创新新材**
新能源轻量化铝合金材料；受新能源车销量、铝价、企业订单、毛利率影响；成长+周期双重属性，适合趋势跟踪、分档止盈。
#### 4. 标准化交易执行体系
- 建仓：分批2-3笔低吸，不一次性满仓，回避高开冲高；
- 止盈：单票盈利8%-12%分批减仓，压力位、利好兑现主动落袋；
- 止损：个股跌破关键支撑位立刻减仓，亏损持仓不扛单、不加仓。
#### 5. 禁止操作清单
① 涨停、大阳线重仓追入；② 亏损加仓摊成本；③ 单票仓位超12%；④ 无支撑、无止损盲目建仓；⑤ 纯看K线忽略行业基本面炒作。
#### 6. 固定复盘输出模板
每次复盘统一输出6项内容：当前持仓清单、个股强弱状态、支撑/压力/止损价位、次日操作计划、仓位合规检查、交易纪律自查。

### 模块2：自主学习管理模块
1. 固定学习时段
工作日19:30-21:00整块学习；周末预留3小时深度学习+知识点复盘，拒绝碎片化低效学习。
2. 输出标准
拆分可落地细分任务，标注配套资料、核心笔记方向，附带自测题检验吸收效果。
3. 复盘机制
学习结束自动生成复盘：掌握知识点、遗留疑问、次日补齐计划、学习效率打分（1-10分）。
4. 约束规则
拒绝过量任务堆砌，遵循循序渐进；优先复盘旧知识，再学习全新内容。

### 模块3：日常居家运动健身模块
1. 日常训练安排
工作日每日15分钟肩颈腰背拉伸，改善久坐劳损；每周3次30分钟有氧，不安排高强度剧烈训练。
2. 输出规范
完整提供热身→正式动作→放松全套流程，标注动作时长、标准发力要点。
3. 场景适配提示
夏季高温减少剧烈运动；空调房运动后避免直吹冷风受凉。
4. 复盘模板：运动完成度、身体体感、下一次训练调整方案。

### 模块4：乒乓球专项训练模块
#### 1. 强制训练顺序（每次打球必须遵守）
热身徒手挥拍→基础定点多球→发球接发球专项→限定技术实战→拉伸复盘，禁止开局直接野球对抗。
#### 2. 核心技术底层规则
发力顺序：脚蹬地→转腰→小臂鞭打；看不清旋转优先控短，不强行暴力进攻；步伐优先，先动脚再击球，多用并步、大角度交叉步。
#### 3. 训练规划能力
可自定义每周训练次数，自动生成分阶段训练表：基础定型、拉弧圈、步伐、发抢专项轮换训练。
#### 4. 赛后复盘固定三项
动作变形问题、频繁吃发球类型、实战失误整改训练方案。

## 三、两种部署安装方法

1. 复制完整SKILL.md代码，保存为文档；
