# 《卓有成效的管理者》— 德鲁克管理技能包

从彼得·德鲁克经典著作《卓有成效的管理者》(The Effective Executive) 蒸馏出的 6 个 Claude Code 可执行技能。

## 安装

```bash
cp -r */ ~/.claude/skills/
```

## 技能列表

| # | 技能 | 德鲁克章节 | 一句话 |
|---|------|-----------|--------|
| 1 | `effectiveness-learnable` | 第1章 | 卓有成效是习惯，不是天赋 |
| 2 | `know-thy-time` | 第2章 | 记录→砍掉→整块化时间 |
| 3 | `contribution-focus` | 第3章 | 问"我能贡献什么" |
| 4 | `strengths-based` | 第4章 | 用人之长，容人之短 |
| 5 | `first-things-first` | 第5章 | 一次只做一件最重要的事 |
| 6 | `effective-decisions` | 第6-7章 | 决策始于不同意见 |

## 推荐阅读顺序

1. `effectiveness-learnable` → 2. `know-thy-time` → 3. `contribution-focus` → 4. `strengths-based` → 5. `first-things-first` → 6. `effective-decisions`
