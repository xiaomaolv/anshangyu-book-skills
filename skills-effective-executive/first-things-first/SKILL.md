# 要事优先

## R — 原文

> 如果说卓有成效有唯一"秘诀"的话,那就是专注。有效管理者总是先做最重要的事,而且一次只做一件事。

## I — 方法论骨架

德鲁克的"要事优先"不等于GTD的"排优先级"。核心区别:

1. **向后看** — 放弃昨日的成功。最危险的不是做错事,而是继续做"曾经对但现在已失效"的事
2. **向前看** — 问自己:"如果现在重新开始,我还会做这件事吗？"如果答案是"不会",立刻停止
3. **勇气优先** — 真正的优先级不是分析出来的,是敢不敢"不做"衬托出来的
4. **一次一件** — 多任务切换的代价远比你感知到的大

## E — 可执行步骤

1. 列出当前所有在做的事
2. 对每一项问:"如果现在重新开始,还会做吗？"不会→砍掉
3. 对剩下的,选唯一一件"最重要"的
4. 把时间整块分配给这一件事,直到完成或达到里程碑,再做下一件

## B — 边界

- 不适用于紧急危机处理(先止血)
- "最重要"可能和"最紧急"不同,需要上级buy-in
