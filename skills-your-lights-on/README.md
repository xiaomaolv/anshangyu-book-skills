# 《你的灯亮着吗》— 问题解决技能包

从 Donald C. Gause & Gerald M. Weinberg 经典著作《你的灯亮着吗？》(Are Your Lights On?) 蒸馏出的 7 个 Claude Code 可执行技能。

## 安装

```bash
cp -r */ ~/.claude/skills/
```

或在项目中使用：

```bash
cp -r */ your-project/.claude/skills/
```

## 技能列表

| # | 技能 | 一句话 | 触发词 |
|---|------|--------|--------|
| 1 | `check-your-lights` | 元检查——出门前灯亮着吗？ | "我懂了就这么办" |
| 2 | `problem-definition-formula` | 问题 = 期望 - 体验 | "说不清哪里不对" |
| 3 | `problem-analysis-3steps` | 谁有问题→问题是什么→从哪来 | "帮我解决X" |
| 4 | `problem-restatement` | 换个说法换种解法 | "只有这些办法了吗" |
| 5 | `solution-chain-awareness` | 每种方案都会生新问题 | "终于搞定了" |
| 6 | `dont-mistake-solution-for-problem` | "我要一个X"不是问题 | "我们需要做X" |
| 7 | `foreign-perspective` | 用外国人/盲人/孩子视角审视 | "一直就这样啊" |

## 推荐阅读顺序

1. `check-your-lights` → 2. `problem-definition-formula` → 3. `problem-analysis-3steps` → 4. `dont-mistake-solution-for-problem` → 5. `problem-restatement` → 6. `foreign-perspective` → 7. `solution-chain-awareness`
